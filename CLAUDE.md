# Folio (repo: research-platform)

Local-first web app for students writing research papers. Hard product rule: the AI must never write the student's paper; see `server/mentor.ts`, which is sent as the system prompt for every model.

- `server/`: Hono server (run with `tsx`, no build step). Stores everything as plain files under `RP_DATA_DIR` (default `~/ResearchPlatform`). `llm.ts` talks to providers with plain `fetch` (OpenAI-compatible for OpenAI/OpenRouter/OpenCode Go, native Messages API for Anthropic). Keys never leave the server.
- `src/`: Vite + React + Tailwind v4 + shadcn/ui (new-york-v4 sources copied into `src/components/ui`). Hash router in `src/lib/router.ts`. Plate editor config in `src/components/editor/`.
- UI rules from the owner: shadcn components (or shadcn-compatible libraries) only, minimal, no clutter.
- Checks: `npm run typecheck` and `npx vite build`.
- PDF viewer is EmbedPDF (headless, PDFium wasm served locally) in `src/components/papers/pdf-annotator.tsx`. Highlights are stored as overlays in `sources/<id>.highlights.json`, not written into the PDF. Note links to highlights use `#hl/<sourceId>/<highlightId>`.
- Knowledge base: `server/knowledge.ts` writes an OKF v0.2 bundle in `<project>/knowledge/` (index.md and log.md are regenerated/appended by code; pages merge per-paper subsections deterministically, the model only returns JSON). Canvas: `server/canvas.ts` + `src/components/canvas/` (React Flow; student drawings are `shapes`/`arrows` in canvas.json saved via PUT `/canvas/drawing`, pen strokes rendered with perfect-freehand). Background AI calls go through `server/ai.ts` and use `settings.defaultModel`.
- References: `server/references.ts` keeps `<project>/references.json` (CSL-JSON array, `id` = citation key) and regenerates `references.bib` on every write. citation-js (`@citation-js/*`) parses BibTeX/RIS and renders CSL; styles/locales are fetched from the CSL GitHub repos into `<data>/.cache/csl`. Notes cite with pandoc `[@key]`; `unescapeCitations` in `src/components/editor/plugins.ts` stops the markdown writer from saving them as `\[@key]`. UI in `src/components/references/` and the Cite button in `src/components/editor/toolbar.tsx`.
- Search and project chat (open-notebook's role): `server/search.ts` is an in-memory BM25 index over page-aware passages of every paper (`sources/<id>.txt`, split on `[page N]`) and the notes, rebuilt when files change. The project chat (no `sourceId`) gets the top passages of papers with `inChat !== false` and cites them as `[Title, p. N](#src/<id>/<page>/<chunk>)`; `src/components/chat/source-cite.tsx` renders those. `src/lib/jump.ts` opens a paper at a page.
- Source kinds: `Source.type` is pdf (default when missing), web, youtube, docx or text. `server/importers.ts` turns links (Readability + linkedom), YouTube captions (innertube player API, `RP_YOUTUBE_URL` for tests) and .docx (mammoth) into light markdown in `sources/<id>.txt`; `src/components/papers/text-source.tsx` is the reader for non-PDF sources. The Summary tab (`src/components/papers/source-summary.tsx`, GET `/sources/:sid/summary`) shows the source's KB Paper page and runs the KB ingest to create it.
- LaTeX: `server/latex.ts` keeps `<project>/latex/` (main.tex from a template; `references.bib` copied from the project's on every compile) and compiles into `latex/.build/` with latexmk (if TeX is installed) or Tectonic (pinned 0.17.0, downloaded on request into `<data>/.tools/`). `RP_LATEX_ENGINE` forces an engine path (tests use a mock). `parseProblems` reads Tectonic and file-line-error output. UI in `src/components/latex/`: CodeMirror 6 with the stex legacy mode and completions for `\cite`/`\ref`/files, and an EmbedPDF preview that loads each new PDF under the old one (each needs its own documentId; a numeric `defaultZoomLevel` breaks layout, so zoom is restored with `requestZoom`). The chat reads the open file via `openNotePath: latex/<file>`. Journal templates live in `server/latex-templates.ts` (only classes shipped in TeX Live/Tectonic; each was compiled with latexmk with and without a citation). Applying one (POST `/latex/template`) keeps the old main.tex as `main-before-<id>.tex` and clears `.build` aux files. Cite inserts `\cite` instead of `\citep` when main.tex doesn't load natbib (`usesNatbib` in latex-editor.tsx).
- PDF text: `readPdf` in `server/sources.ts` uses `@firecrawl/pdf-inspector` (napi-rs native; no Intel Mac build) and falls back to unpdf (pdf.js). It writes per-page markdown after `[page N]` and stores `scannedPages`/`extractor` on the Source. `upgradePdfText` re-reads PDFs without `extractor` once at server start. `RP_PDF_READER=pdf.js` forces the fallback. Search snippets go through `plainText` (search.ts); the citation popover renders the passage as markdown.
- Sidebar: `src/components/sidebar/library.tsx` renders Starred/Sources/Notes (foldable; folded state in localStorage `rp-folded:<pid>`). Stars and folders are virtual, in `<project>/organize.json` (`server/organize.ts`; keys `s:<id>`/`n:<path>`; renaming a note moves its key). Template previews are `public/latex-templates/<id>.png`, made by `scripts/latex-previews.mts` (needs TeX + pdftoppm).
- Export: `server/export.ts` runs pandoc (`RP_PANDOC`, Folio's own download pinned 3.6.4 in `<data>/.tools/pandoc-3.6.4/`, or PATH) with `--citeproc`, the project's CSL JSON and a .csl file from `references.styleFile` (journal styles resolve to their parent). Notes are joined with page breaks; asset image URLs become file paths; `#hl/`/`#src/` links are dropped. PDF uses the LaTeX engine (`--pdf-engine` xelatex/lualatex/pdflatex or Tectonic). Output in `<project>/exports/`. UI `src/components/export/export-dialog.tsx` (note header, Thesis "Export thesis").
- Writing feedback: `server/feedback.ts` (offline `rules` + `aiReview`; issues quote exact words; `stripSuggestions` removes model-suggested wording; quotes not found in the text are dropped). POST `/projects/:id/feedback {notePath|latexPath, ai}`. UI `src/components/feedback/feedback-panel.tsx`: notes mark quotes with the CSS Custom Highlight API (`::highlight(rp-issues)` in index.css, no editor changes); LaTeX uses `LatexEditorHandle.find/select`.
- Similarity self-check: `server/similarity.ts` (offline, project sources only). Indexes word triples per source (`[page N]` gives pages; cached by text), finds runs of 8+ words in source order (joined across 1-3 changed words → `close`), then sentences sharing ≥50% of their triples with one source (`close`, replacing its copied pieces). Quotes (“…”, "…", `>` blockquotes via `quoteBlockquotes`, LaTeX ``…'' via `latexQuotes`) are `quoted`; `cited` uses feedback's `CITED`. POST `/projects/:id/similarity {notePath|latexPath}`. UI is the Sources tab of the feedback panel (`src/components/feedback/similarity-check.tsx`).
- Thesis plan: `server/thesis.ts` keeps `<project>/thesis.json` (chapters linked to a note or LaTeX file, goals, due dates, milestones, plus a daily `log` of total words for today/this week). Counting is in `server/wordcount.ts` (prose only). `thesis.brief` goes into the mentor prompt. UI `src/components/thesis/thesis-view.tsx` (shadcn Calendar via react-day-picker 9, Progress).
- Literature matrix: `server/matrix.ts` keeps `<project>/matrix.json` (columns, `cells[sourceId][colId] = {text, by: ai|student, none?}`, hidden rows). `fill` sends the source's text highlights as `[hN]` (plus BM25 passages as `[PN]` when highlights are thin) and stores markers `[h:<hlId>:<page>]` / `[p:<page>]`; it never overwrites `by: "student"` cells. UI `src/components/matrix/matrix-view.tsx`.
- Supervisor feedback: `server/supervisor.ts` keeps `<project>/supervisor/reviews.json` (rounds with `items[{type comment|insert|delete|replace|markup, author, date, page?, anchor?, text, status open|done|declined, reply?}]`) and the original file as `<id>.docx|pdf`. `fromDocx` reads `word/comments.xml` and anchors via commentRangeStart/End, and turns `w:ins`/`w:del` into suggested edits (a delete then insert in one paragraph is a "Replace"); `fromPdf` reads unpdf annotations (Text/FreeText/markup; anchors cut from the page text inside the quads). `brief` puts open comments in the mentor prompt. UI `src/components/supervisor/supervisor-view.tsx` (view `supervisor`).
- Find papers: `server/discover.ts` searches OpenAlex, Semantic Scholar, arXiv (Atom via linkedom) and Crossref, merges duplicates (DOI/arXiv id/title+year), and walks related/citing/references (OpenAlex filters, S2 fallback). Unpaywall isn't called directly (it needs an email); OpenAlex's OA locations come from it. POST `/projects/:id/discover/add` adds the reference (DOI lookup, else `toCsl`) and, with `withPdf`, the free PDF as a source. Base URLs `RP_OPENALEX_URL`/`RP_S2_URL`/`RP_ARXIV_URL`/`RP_CROSSREF_URL` for tests. UI `src/components/discover/discover-view.tsx` (view `discover`; `page` = a seed DOI for related papers).
- Deletes go to `<data>/.trash`, never hard-delete user files.
- Note editor extras: `[[Note]]` / `[[Note|text]]` links (decoration in `src/components/editor/note-links.tsx`, resolve by path or name; `server/links.ts` gives backlinks and rewrites links on rename). `/` menu, `[@` reference picker and `[[` suggestions share `inline-menu.tsx` (keys are caught in the capture phase). Drag handles use `@platejs/dnd` (`block-draggable.tsx`). Tables are `@platejs/table` (GFM; table plugins sit after List/Indent so Tab moves cells). Callouts are blockquotes starting with `[!note]`. `unescapeCitations` also unescapes `[[`, `[!x]` and strips zero-width spaces. Note history: `server/history.ts`, copies in `<project>/.history/notes/` at most every 10 min. Outline rail: `outline.tsx` (only when the editor is ≥1200px wide).
- Install and launch: `scripts/install.sh` / `install.ps1` (one-line installers; download a checksum-checked Node 22 into `~/Folio/node` or `%LOCALAPPDATA%\Folio\node` and the code tarball into `.../app`; re-running updates). `scripts/launch.mjs` (`npm run folio`; `--background`, `--stop`, `--setup`) runs `npm ci` only when package-lock's hash changes and `vite build` only when sources are newer than `dist/`, and checks GET `/api/health`. `scripts/shortcut.mjs` (`npm run shortcut`) makes `~/Applications/Folio.app`, Windows Desktop/Start shortcuts or a Linux .desktop. Icons: `public/folio-icon.svg` → `icon-*.png`, `folio-1024.png`, `folio.ico`; PWA manifest `public/manifest.webmanifest`.
- Docs: `README.md` is Iraqi Arabic, `README.en.md` English, both short; feature detail is in `docs/GUIDE.md` / `docs/GUIDE.ar.md`; rules for contributors in `CONTRIBUTING.md`. New features get a section in the guide, not the README.
